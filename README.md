## Personal Website & Portfolio

Welcome to the repository for my personal website! This project is designed with minimalist aesthetic and responsive layouts. It serves as a digital space to share my background and personal interests.

## 🌟 Features

*   **Clean & Minimalist UI:** A design that utilizes ample whitespace and readable typography (including *Source Serif 4* and *Caveat*).
*   **Fully Responsive:** Built with CSS Flexbox to ensure the layout looks great on everything from large desktop monitors to mobile screens.
*   **Interactive Elements:** Subtle CSS transitions and hover effects to provide a tactile, modern user experience.

## 🛠️ Tech Stack

*   **HTML:** Semantic markup for structure.
*   **CSS:** Custom styling, animations, flexbox layouts and vector drop-shadows.
*   **SVG:** Scalable Vector Graphics for crisp, resolution-independent image.
